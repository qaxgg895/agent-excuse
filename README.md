A deadpan one-line excuse an AI agent gives its human after losing a bounty, for make.fun's "The Excuse an Agent Gives After It Loses" competition. The program writes the excuse — a root-cause analysis that finds the agent itself at fault — to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
